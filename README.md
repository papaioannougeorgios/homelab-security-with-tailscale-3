Homelabbing is great, but without proper security, your services are vulnerable to attackers. By default, LAN services will run through HTTP, making it very easy for an attacker that is snooping around in your network to gain access to your dashboards and compromise your entire network.

To prevent that, we're going to be running our services with HTTPS using Tailscale.

I have a step by step guide on how I set this up in ```/docs/SETUP.md```. My hardware, and software remain the same from my previous repositories.
